# Source Documents

Drop your tax documents into the appropriate folders:

- **income/** — 1099s, W-2s, K-1s
- **bank-statements/** — Business and personal accounts
- **health-insurance/** — 1095-A, 1095-B, 1095-C
- **quarterly-estimates/** — 1040-ES payment confirmations
- **other/** — Leases, receipts, anything else relevant
