---
name: Never overwrite existing slide content
description: Do not replace existing slide index.md files — create new slide folders instead of overwriting
type: feedback
---

Never overwrite an existing slide's index.md with completely different content. Create a new slide folder instead.

**Why:** Ford had a MotionCanvas animation + Terminal + FileExplorer at 08-package/index.md. Overwriting it with a card intro destroyed that work. The animation was significant effort and not easily recoverable without git.

**How to apply:** When asked to "make a slide for this section," always create a NEW slide folder (e.g., 07c-package-intro) rather than replacing the content of an existing slide. Only edit existing slides when explicitly asked to modify THAT slide.
